# 煎記訂單後端（Google Apps Script + Google 試算表）

網站結帳 → `Code.gs`（GAS 網頁應用程式）→ Google 試算表「訂單」「訂單明細」兩個工作表。

## 設定步驟
1. 打開 Apps Script 專案，把 `Code.gs` 的內容**全部**貼上並取代原內容，然後存檔。
2. 視需要修改最上方的 `CONFIG`：
   - `SPREADSHEET_ID`：留空會自動建立「煎記 JIAN JI 訂單」試算表。也可以填入既有試算表的 ID（網址中 `/d/` 和 `/edit` 之間那段）。
   - `NOTIFY_EMAIL`：填店家的 Email，每張新訂單都會寄通知信。
3. 上方函式選單選 `setup`，按 **執行**，並完成授權。執行紀錄會印出試算表網址。
4. **部署 → 新增部署作業 → 類型：網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 複製 `https://script.google.com/macros/s/.../exec` 網址，填入 `index.html` 的 `const ORDER_API = '...'`。

## 之後修改程式碼
請用 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本**。這樣網址不會變，網站不用重改。

## 安全設計
- 金額由後端依 `CATALOG` 價目表重新計算，前端傳來的價格不採用。網站新增或修改品項時，請同步更新 `CATALOG`。
- 後端會驗證手機、取餐方式、宅配地址和數量，並用 LockService 避免同時下單時訂單編號重複。
- 有一個隱藏欄位用來擋掉機器人送出的訂單。若輸入內容以 `= + - @` 開頭，會自動加上前綴，避免被試算表當成公式執行。
